# 暗算ゲーム

## 概要

「暗算ゲーム」は、ブラウザ上で遊べる暗算トレーニング用Webアプリです。

簡単な1桁同士の足し算から、難しい2桁同士の掛け算まで、ランダムに10問出題されます。ゲーム終了後には、正解数・正答率・評価コメントが表示されます。

Dockerコンテナ上で動作し、ブラウザから利用できます。

---

## 主な機能

- タイトル画面
- ゲーム開始
- 全10問のランダム出題
- 問題ごとの難易度表示
- 現在の問題番号表示
- 正誤判定
- 正解数の記録
- 正答率の表示
- 評価コメント表示
- もう一度遊ぶ
- タイトル画面へ戻る

---

## 出題される問題

- 1桁同士の足し算
- 1桁同士の引き算
- 1桁同士の掛け算
- 2桁同士の足し算
- 2桁同士の掛け算

問題はランダムに出題されます。

## 実行方法

### 1. リポジトリを取得

```bash
git clone （GitHubのURL）
cd math_game
```

### 2. Dockerコンテナを起動

```bash
docker compose up --build
```

### 3. ブラウザでアクセス

```
http://localhost:5000
```

### 4. コンテナの停止

```bash
docker compose down
```

---

## 遊び方

1. タイトル画面で「ゲーム開始」をクリックします。
2. 表示された暗算問題に答えます。
3. 全10問回答すると結果画面が表示されます。
4. 結果画面では正解数・正答率・評価コメントを確認できます。
5. 「もう一度遊ぶ」または「タイトルへ戻る」を選択できます。
